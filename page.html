API Reference

Welcome to the AuthAPI documentation. This API provides simple user management and protected product retrieval using JWT-style Bearer tokens.

Base URL

https://login-logout-alpha.vercel.app

Authentication

All protected routes require a Bearer token to be passed in the Authorization header.

Authorization: Bearer mytoken
GET /create-user

Utility endpoint to generate a test user in the MongoDB database.

Response

Field Type Description
_id String Unique user identifier
username String The created username (default: "admin")
password String The created password (default: "1234")
POST /login

Authenticates a user and returns a static session token.

Request Body

"username": "admin", "password": "1234"

Status Codes

200 Success. Token returned.
401 Unauthorized. Invalid credentials.
GET /products

Returns an array of product objects. Requires Authentication.

Headers

Authorization Bearer mytoken

Success Response

[ { "id": 1, "name": "iPhone 15", "price": 80000 }, ... ]
