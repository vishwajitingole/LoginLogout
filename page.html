API Endpoints

POST
/login
Description:
Authenticate user credentials and generate Bearer token.

Headers:
Content-Type: application/json

Request Body: 
{
  "username": "admin",
  "password": "1234"
}
Success Response: 
{
  "message": "Login Successful",
  "token": "mytoken"
}
Status Codes:
200 → Success
401 → Invalid Credentials
GET
/products
Description:
Protected products endpoint.

Authorization:
Bearer Token Required 
Authorization: Bearer mytoken
Success Response: 
[
  {
    "id": 1,
    "name": "iPhone 15",
    "price": 80000
  },
  {
    "id": 2,
    "name": "Samsung S24",
    "price": 70000
  }
]

/create-user

Demo Credentials:

Response:

  "message": "User created"
}

Frontend Integration Flow

STEP 1
Login User
Send login credentials to /login. Save returned token inside localStorage or app state.
STEP 2
Attach Token
Add Bearer token inside Authorization header for all protected routes. 
Authorization: Bearer mytoken
STEP 3
Fetch Products
Access protected APIs like /products and render product data inside frontend UI.
